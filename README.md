# 背诗小状元 📜

> 📱 **安卓直接安装**：下载 [apk/背诗小状元-v2.4.1.apk](./apk/背诗小状元-v2.4.1.apk) 传到手机点击安装（需允许安装未知来源应用）。

给孩子（小学五年级）的古诗背诵闯关应用。内置河北小学五年级古诗集（原书"古诗词诵读（五）"分册）**99 首**（从 PDF 逐页高清渲染、人工逐句核读导入），每首配背景故事、诗意寓意、逐句讲解、作者介绍、词语解释（默认收起、点击展开）、拼音标注、按诗意定制的卡通动画场景，视频讲解为 B 站/抖音搜索直达入口。

## ✨ 功能

- 🏠 **首页**：今日打卡、连续天数、总积分与等级进度（小书童 → 背诗小状元）、今日推荐诗
- 📖 **诗集**：99 首诗卡，搜索/筛选（未背过/已背过），星级与最快纪录展示
- 📜 **诗页**：主题卡通场景配图、大字诗文+拼音开关、四块折叠资料、B 站视频内嵌播放
- 🎤 **背诵挑战**：全屏计时 → 家长判定背过/没背过（可选语音辅助对照）→ 得分
  - 积分规则：背过 +10，首次背会 +30，破个人最快纪录 +20，每日首次打卡 +5，完成目标 +50
  - 破纪录/首次背会时全屏彩带庆祝 + 号角音效
  - 单诗星级：背过 1★ → 连背 2★ → 3★ 滚瓜烂熟
- 📅 **时间线**：月历打卡热力图 + 按天明细（哪天背了什么、用时、结果、积分、破纪录标记）
- 🎯 **打卡目标**：连续打卡 N 天 / 累计背 N 次 / 背会 N 首，自定义奖励（如"去游乐园"），完成自动 +50 分并标记待兑现
- ➕ **添加古诗**：粘贴诗文自动识别（诗题/朝代/作者/诗句），或输入网页链接抓取解析；保存时**自动匹配内置知识库**（覆盖 83 首课本常见名篇+99 首内置诗），一键生成背景故事、诗意寓意、逐句讲解、作者介绍、词语解释与视频搜索入口；未收录的诗会留出编辑引导
- ⚙️ **设置**：孩子昵称与头像、数据导出/导入备份（JSON）、自建诗管理

## 🚀 使用

### 家里用（手机与电脑同一 WiFi）

1. 电脑安装 [Node.js](https://nodejs.org/)（首次需要）
2. 双击 `start.bat`（首次自动构建，之后直接启动）
3. 手机浏览器打开控制台里显示的 `http://电脑IP:4173`

### 打包成安卓 APK（独立安装）

已用 Capacitor 打包好安卓项目。以后修改了应用想重新打包，双击 `build-apk.bat` 即可（会自动：构建网页 → 同步 → 编译 APK → 复制到上级目录 `背诗小状元.apk`）。

- 构建环境（已装好）：JDK 21 在 `D:\mywsl\tools\jdk21`，Android SDK 在 `D:\mywsl\tools\android-sdk`（Gradle 走腾讯镜像）
- 首次产物：`D:\mywsl\projects\games\背诗小状元-v1.0.apk`（约 4MB，debug 签名，自用安装没问题）
- 安装方法：把 APK 传到手机（微信/QQ/数据线均可），点击安装，若提示"未知来源"选择允许
- 数据仍在 App 内本地保存，卸载会清空——卸载前记得在应用「设置」里导出备份，装新版后导入恢复

### 像原生 App 一样用（可离线）

把 `dist` 目录部署到任意静态托管（Vercel / Netlify / GitHub Pages 均免费且自带 HTTPS），手机浏览器打开网址后选"添加到主屏幕"，即可全屏运行、离线可用。部署后需再执行 `node scripts/gen-sw.mjs` 生成离线缓存。

> 说明：离线缓存（Service Worker）需要 HTTPS 环境；局域网 `http://` 访问时在线使用不受影响。

### 开发

```bash
npm install
npm run dev        # 开发服务器
npm run build && node scripts/gen-sw.mjs   # 生产构建 + 离线缓存
node server.mjs dist 4173                  # 本地静态服务
```

## 💾 数据说明

- 全部背诵记录、积分、目标都存在**手机浏览器本地**（localStorage），不上传任何服务器
- 换手机 / 清理浏览器前，务必在「设置」里**导出备份**，再在新设备导入恢复
- 以后想打包成安卓 APK：用 [Capacitor](https://capacitorjs.com/) 直接包 `dist` 目录即可（`npx cap init && npx cap add android`，把 webDir 指向 dist）
